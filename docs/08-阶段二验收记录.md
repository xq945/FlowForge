## 4. 过程中发现并修复的问题

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| 注册返回 `createdAt: null` | MyBatis-Plus 的 insert 不回填数据库默认值 | 插入后回查一次 |
| `X-Trace-Id` 响应头出现两次 | 网关与下游服务都写该头 | 路由加 `dedupeResponseHeader` |
| 401 响应体 `traceId` 为空 | WebFlux 无 MDC 上下文 | 增加显式传 traceId 的重载方法 |
| **连续 5 次密码错误仍能登录** | `login` 标注 `@Transactional`，抛业务异常时把失败计数一起回滚 | 移除登录方法的事务，失败计数靠单条 SQL 自动提交 |
| Nacos 容器反复 `exit 255` | 3.0 启动脚本强制要求 token 与 identity 环境变量 | 补全环境变量 |
| Nacos 注册 403 `User not found` | 3.0 不再自动创建内置账户 | 本地关闭鉴权 |
| 网关端口冲突 | 8080 被其他 Java 服务占用、8082 被 offerget 占用 | 网关固定 8083 |
| RabbitMQ 端口冲突 | LegacyGuard 已占用 5673/15673 | 改为 5674/15674 |
| Docker Hub 拉取 Nacos 镜像失败 | 直连 registry 超时 | 经 `docker.m.daocloud.io` 拉取后重命名 |
